Atur jadwal ujian Anda di sini. Pengaturan ini mempengaruhi apakah siswa bisa login atau tidak.

Pilih kriteria lalu tekan tombol tampilkan untuk mulai mengedit/menambah.

Lihat contoh format penulisan (Klik di sini) 
[
  {
    "text": "Pertanyaan ditulis di sini...",
    "image": "https://link-gambar.com/gambar.jpg",
    "options": [
      "Pilihan A",
      "Pilihan B",
      "Pilihan C",
      "Pilihan D",
      "Pilihan E"
    ],
    "correct": 0,
    "category": "Mata Pelajaran"
  }
]

Catatan: "correct": 0 berarti Jawaban A. Kosongkan "image": "" jika tidak ada gambar.

Format soal Essay (tambahkan "type": "essay" dan "keywords", tanpa perlu "options"/"correct"):

[
  {
    "type": "essay",
    "text": "Jelaskan prinsip keseimbangan dalam DKV...",
    "keywords": "keseimbangan, simetris, asimetris, komposisi",
    "idealAnswer": "(opsional) contoh jawaban ideal untuk referensi guru",
    "category": "Mata Pelajaran"
  }
]

Soal import otomatis akan menyedot pengaturan dari *Saring Soal* di atas (Kelas/Jurusan/Mapel).
